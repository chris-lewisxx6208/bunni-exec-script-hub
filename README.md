## Overview

Bunni Exec provides Roblox users with a dedicated Windows desktop environment for loading and executing Lua scripts. Its compact layout combines script management, a built-in hub, and debugging tools so these tasks can be handled from one application on 64-bit Windows computers.

Designed for Windows 10 and Windows 11, the executor also includes auto-update functionality and a queue that remains available between launches. This gives users a lightweight way to keep their local script workflow organized.

## Frequently Asked Questions

**Which operating systems can run Bunni Exec?**  
Bunni Exec is intended for Windows 10 and Windows 11 on 64-bit systems.

**Will Roblox updates always be supported?**  
Compatibility may vary after updates to Roblox or Bunni Exec. Use matching versions and check the relevant update notes.

**What does Bunni Exec provide beyond a script hub?**  
It brings execution, script hub access, queue management, and debugging together in a single Windows desktop application.

**Can script executor use affect my Roblox account?**  
Use remains subject to Roblox rules and your own responsibility. Review the applicable terms before executing scripts.

**Is local script information retained?**  
Yes. The profile supports a persistent queue and SQLite-related local storage behavior.
